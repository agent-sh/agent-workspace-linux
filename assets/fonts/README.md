# Viewer typeface

Inter Variable 4.1 is bundled from the official [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1).
`InterVariable.ttf` is unmodified. The viewer embeds it in the binary and registers
its `Inter Variable` family with GPUI before opening a window.

The font is distributed under the SIL Open Font License 1.1. See [LICENSE.txt](LICENSE.txt).
The same copyright and full license are embedded in every binary and available
through `agent-workspace-linux viewer font-license`, including without a display.
